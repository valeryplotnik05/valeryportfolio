# Валерия Плотникова — сайт-визитка

Лаконичный одностраничный сайт-визитка в нежной голубой палитре с мягкими градиентами, плавными анимациями и стеклянным (glassmorphism) эффектом интерфейса.

## ✨ Особенности

- **Адаптивный дизайн** — корректно отображается на десктопе и мобильных устройствах
- **Плавные анимации** при загрузке и взаимодействии (fade-in, slide-down, вращающееся кольцо вокруг фото)
- **Стеклянная навигация** с эффектом размытия фона (`backdrop-filter`)
- **Аккуратная типографика** — сочетание шрифтов Cormorant Garamond и Montserrat
- **Блок «О себе»** с информацией об образовании, дипломах и ключевых навыках
- **Прямая связь** через Telegram

## 🛠 Технологии

- HTML5
- CSS3 (Custom Properties, Flexbox, анимации, градиенты, blur-эффекты)
- Google Fonts (Cormorant Garamond, Montserrat)

## 🚀 Запуск

Сайт представляет собой единый HTML-файл и не требует сборки или установки зависимостей:

```bash
open index.html
```

или просто откройте файл `index.html` в браузере.
